# MedCare-UIUX
Low-fidelity UI/UX design for a healthcare appointment booking app.

## About the Project
MedCare is a healthcare app concept designed to help users find nearby hospitals, explore doctors and specialists, and book appointments easily.

## Key Features
- Find nearby hospitals
- Browse doctors and specialists
- View doctor details
- Select appointment date and time
- Book doctor appointments

## Tools Used
- Figma
